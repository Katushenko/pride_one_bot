# Pride One Bot

Telegram-бот для записи на занятия студии **Pride One**.

## Возможности

- Просмотр еженедельного расписания
- Запись на занятия (ближайшие 2 недели)
- Отмена записей с подтверждением
- Календарь посещений со статистикой

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/schedule` | Еженедельное расписание |
| `/available` | Свободные занятия |
| `/bookings` | Мои активные записи |
| `/calendar` | Календарь посещений |

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

## Структура проекта

```
pride_one_bot/
├── bot.py          # Хэндлеры, inline-кнопки, логика
├── database.py     # SQLite: расписание, записи, пользователи
├── requirements.txt
└── README.md
```

## База данных (SQLite — pride_one.db)

| Таблица | Содержимое |
|---------|-----------|
| `users` | Telegram-пользователи |
| `schedule` | Еженедельное расписание занятий |
| `bookings` | Записи на конкретные даты |

При первом запуске создаётся расписание:
Пн 09:00 Йога · Вт 10:00 Пилатес · Ср 18:00 Зумба · Чт 09:00 Йога · Пт 17:00 Силовая · Сб 11:00 Растяжка · Вс 10:00 Воскресная йога
